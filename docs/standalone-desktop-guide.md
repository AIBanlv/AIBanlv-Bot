# 角色来源、Key 配置与平台服务

未扫码也可以查询和切换公共角色，首次启动默认使用上官婉儿。设备绑定页分为“扫码登录 / Key 配置”：
DeepSeek / Realtime Key、地域、业务空间、模型和音色统一在 Key 分页填写，切换分页保留未保存草稿。
在形象设置页切换公共角色，扫码后还可以选择自己的私人角色。
上官婉儿首次加载需要下载公共形象资源；语音口型需要本机对应的 LAM 运行环境。
本地角色导入/编辑将在后续版本增加，当前不提供入口，也不读取旧版的本地形象配置。
加载失败时显示原因，可以重试或刷新公共角色列表，不会切换成备用二维形象。

游客角色列表使用 `GET /jwt/client/desktop-public/roles`，不携带 JWT，也不接受租户或用户参数。
只返回无个人归属的公共角色和展示所需字段；扫码后私人角色仍走原受保护接口。
服务端保留同一数据库并发预算、SQL 超时和超载 503。需要先部署配套服务端接口。

## 调用来源

- 线上角色：包含默认婉儿、公共角色及缓存到本机的线上形象，必须连接平台并扫码，沿用账号积分与临时凭据。
- 本地角色：使用自有额度，已配置 Realtime 则语音，否则使用 DeepSeek 纯文字；缺配置时提示，不回退平台。
- 本地 DeepSeek：Harness 客户端已连接并登录时优先使用客户端账号，未登录时使用填写的 Key。
- 电脑助手也保留 Harness 账号优先；其模型费用与线上角色的平台语音费用分别计算。

费用来源由所选角色决定，不再手动选择。旧版保存的 source 设置不能绕过角色规则；
Key 失效、余额不足或网络故障都不会跨费用来源自动回退。线上角色余额不足时需充值。
DeepSeek 每次新调用按客户端是否连接登录确定来源；客户端退出或登录变化会停止在途任务，不自动换 Key 重做。
自有 Key 仍会消耗对应供应商的额度，不代表供应商免费。

Realtime 填写自己的地域、Workspace ID、模型与音色。默认公共模型为
qwen-audio-3.0-realtime-flash / longanlingxi，北京和新加坡使用各自的 Key 与业务空间；平台私有
音色不自动用于自己的账号。该模型还支持 longanlingxin、longanlingxi、longanxiaoxin、longanlufeng，
不使用 Tina。依据[阿里云接入文档](https://help.aliyun.com/zh/model-studio/qwen-audio-realtime-user-guides)。
旧版保存的默认组合 `qwen3.8-omni-flash-realtime / Tina` 会在启动时更新为上述默认值；其他自定义组合保留。
更新后主动保存的模型和音色不会再被迁移覆盖；如需更换，请在“设备绑定 → Key 配置”中修改并保存。
模型或音色无权限时显示失败，由用户调整；不偷偷改用平台服务。

两个 Key 各自保存/测试/清除。勾选记住后使用系统 safeStorage 加密，未勾选则只保留
在本次进程；完整 Key 不回显、不进入云同步。测试连接使用供应商服务。
Realtime 测试使用当前表单内容，Key 留空时复用已配置的 Key。
DeepSeek 测试优先测试当前填写的 Key；留空且 Harness 客户端已连接登录时测试客户端，否则复用已保存的 Key；
测试不会保存或清空草稿，也不会开启 Harness。
测试成功后，点击“保存模型设置”才会将该配置用于正常对话。
保存新 DeepSeek Key 后自动供内置电脑助手使用，可在 Harness 页关闭。
Key 只在“设备绑定 → Key 配置”填写一次；Harness 页提供开关、当前来源、配置跳转、测试和日志。
复用客户端登录需安装[连接插件](../demos/web-desktop-pet/harness-client-plugin/README.md)，不读取或导出登录凭据。
已登录客户端接收原生电脑任务并沿用其权限设置；客户端离线时内置助手提供已有受限工具。
平台语音配合 DeepSeek 助手时，两部分分别按其来源计费；使用客户端账号也会消耗该账号的供应商用量。

## 平台与记录

进入“扫码登录”分页会自动连接并获取二维码，无需先保存模型设置；“刷新登录二维码”
可重新获取。页面不再提供“连接账号和手机”开关；旧版保存为关闭时，进入设备绑定页也会自动恢复连接。
扫码后可同步线上角色记录、接收手机指令。网络断开时，公共角色仍可显示，线上对话暂停；
本地角色的自有模型对话不依赖平台连接。
Key 分页保存不会自动连接平台。使用手机 App 扫码；私有角色、音色、账号、
手机指令继续沿用设备证明/JWT/账号归属校验。断开平台不影响自有模型。
记录归属和平台权限独立：离线重启恢复最后的本地记录归属，不据此授予任何云权限；
服务器确认解绑后进入新游客批次，扫码另一账号不会接收前一账号记录。

用户文字在模型调用前写入本机加密档案；助手流式文本最多每 500 ms 保存一次，完成、
打断和退出时保存末态。模型上下文最多 40 条，完整档案不按此窗口裁剪。物理断电可能
丢失最近未完成的写入；读取或保存失败会停止新对话，不以空档案覆盖原文件。
当前单个档案限制为 10 万条、明文 UTF-8 JSON 40 MiB，且加密文件不超过 64 MiB；达到上限后提示导出/清理并停止
新写入，不静默删除旧记录；大规模档案可后续迁移到分区数据库。

旧手机来源、没有历史回执 ID 的用户输入只作本地镜像，由手机原有链路保存；不重新
上传造成重复。线上角色的桌面回复和输入通过稳定 ID 与服务端回执补传。

扫码后只认领线上游客批次，归属固定为该账号；服务端确认后仅标记已同步，保留本机档案。
本地角色记录使用独立分区，扫码、重启、切回线上角色均不会认领或补传。本地任务结果及通知也不进入平台对话或任务汇报。
旧版缺少来源的记录按线上历史兼容，不因本次更新删除。断网、重启和重复 ACK 不改变账号归属。
不上传本地角色、形象 ZIP、模型文件或 Key；调用模型所需上下文仍发送给所用模型服务。

Key 配置分页可导出/清除当前角色来源及身份的本地档案。导出文件是明文，需自行保管；清除不删除
云端历史或其他账号的本地档案。旧 guest-memory 在成功迁移后清空；旧版客户端不能
读取新档案，降级前先导出。模型调用仍会将必要上下文发给所选供应商。

## 验证命令

根目录 `npm test`。Demo 内 `node tests/device-standalone-electron.mjs` 验证独立运行，
`DEVICE_JWT_ONLY=1 node tests/device-electron.mjs` 验证原扫码 JWT 链路（PowerShell 使用
`$env:DEVICE_JWT_ONLY='1'`）。两者只访问本地服务夹具，不使用真实收费会话。
