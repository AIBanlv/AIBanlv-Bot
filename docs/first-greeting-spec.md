# 首次使用欢迎语

- 参考移动端在 `session.updated` 就绪后发送欢迎语的顺序。桌面新用户完成扫码绑定或本地 Realtime 配置、形象渲染和语音推理就绪后，自动使用当前角色的声音问候一次，无需发送消息。
- 简体中文文案：“很高兴认识你，以后由我来陪伴你工作。”其它界面语种提供对应翻译。沿用当前人设的表演、音频、口型及实时信息展示，不把内部播报提示伪造成用户发言。
- 仅首次新建本机用户数据目录的设备有待播问候，未配置或未就绪可以重启后继续等待。已有设备升级不补播；重启、重连、切换账号/角色、清除聊天记录均不重置本机标记。
- 隐藏窗口、正在对话、形象未就绪、语音未就绪、纯文字模式、未鉴权、积分待确认或不足时不发起。沿用既有模型路由与计费，不以本地 Key 绕过线上积分，也不为欢迎语单独建立付费会话。
- 在生成前先持久化领取标记，避免断网、异常退出后重复生成/计费；生成一旦尝试就不自动重放。存储异常只跳过问候，不影响程序其它功能。无法播放时不声称已播报。
- 欢迎语使用独立的内部 `greeting` 标识，禁用所有电脑、提醒与任务工具，无远程任务来源，不复述历史任务。退出清除等待计时器。
- 单元测试与本地 Realtime/LAM/浏览器夹具验证，不调用真实云会话，不修改移动端、不打包。
