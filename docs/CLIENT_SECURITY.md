# 源码端权限与本地数据说明

适用于本仓库 2026-11-04 的源码修改。安装包是否包含这些改动，以对应发行版本为准。

## 执行任务时的确认

- **Codex：** 自建任务继续使用 `workspace-write` 和 `on-request`。超出宿主现有授权的命令、文件修改和权限请求会显示本机确认框，展示任务、工作目录和请求详情；模型的“允许”意见不能替用户确认。额外权限只授予当前轮次。取消、关闭、超时或任务结束后，未完成的确认不会继续授权。外部已有会话仍只读监控。
- **WorkBuddy：** 桌面发起任务前，通过本机运行时的 `--help` 确认支持 `dontAsk`。这个模式只使用宿主预先允许的工具，其他操作拒绝；不会回退到 `auto`。不支持该模式时，请更新 WorkBuddy，或在 WorkBuddy 客户端内执行并授权。权限拒绝会显示任务未全部完成。
- **已连接的 Harness 客户端：** 每次电脑任务先在本机选择工作目录并确认任务，再创建宿主会话。取消、目录不可用或断线时不执行；不再默认使用用户主目录。普通文字聊天和只读汇报不弹目录选择框。

工作目录指定的是任务起点，本身不限制进程访问其他目录。实际文件、网络和工具权限仍由宿主及操作系统执行。不要在宿主中为不可信任务预先开放全部权限。上述改动不替代完整的提示注入防护，也不能保证任意 shell 都无法访问目录之外。

源码更新后需退出并重开 AIBanlv；Harness 若复制了连接插件，需要同步更新并重新加载。未声明支持工作目录协议的旧连接插件只能用于聊天，电脑任务会提示升级。连接插件路径为 `demos/web-desktop-pet/harness-client-plugin`，不是独立插件项目的目录。

## 数据保存在哪里

默认用户数据目录：Windows 为 `%APPDATA%\Control Device`，macOS 为 `~/Library/Application Support/Control Device`。开发者显式设置 `PET_DEVICE_USER_DATA` 时以该目录为准。“本地文档”可打开实际角色目录。

| 内容 | 数据目录下的位置 | 保存方式 |
| --- | --- | --- |
| Realtime / DeepSeek Key | `model-settings.json` / `assistant-settings.json` | 选择记住后通过系统加密保存 Key；配置文件中的普通设置不全是密文 |
| 本地角色、人设、长期记忆 | `local-companion/characters/<角色 ID>/` 下的 `character.json`、`IDENTITY.md`、`SOUL.md`、`MEMORY.md` | 明文，不是加密保险箱 |
| 本地角色的每日对话 | 同一角色目录下的 `memory/YYYY-MM-DD.md` 与 `.jsonl` | 明文；仅截取近期内容参与对话不等于自动删除旧文件 |
| 导入素材 | 同一角色目录下的 `avatar.zip`、`avatar.png`、`voice-sample` | 本地副本，退出或重启仍保留 |
| 本地动态 | `local-companion/moments.json`、`schedules.json` | 明文内容和生成计划 |
| 主动保存的截图 | `captures/screenshot-*.png` | 图片文件，没有自动到期删除承诺 |
| 助手诊断 | `assistant.log` 及其轮转文件 | 有脱敏处理，仍应检查后再公开分享 |

自备 Key 的云端模型仍需联网。语音、声音复刻发送至百炼；文字、工具任务及其必要上下文发送至所选模型或 Harness 宿主。启用本地动态时，会使用当天的部分对话调用 DeepSeek。连接插件还会传递本次已确认的工作目录，不传宿主登录凭据。

“截图”会保存到本机，单独截图不等于已经发送。请求发送文件/截图时，内容传给当前绑定的手机会话，可能通过 TURN 中转；任务完成回执截图临时保存在内存中再尝试发送。宿主的看屏工具也可能把画面作为模型输入，应按宿主权限设置使用。

## 导出与清理

1. 在模型设置中使用“导出当前记录”“清除当前本地记录”，处理当前身份的会话存储和待同步消息。导出的 JSON 是明文。这个入口不会删除已同步的云端记录，也不会清除本地角色目录中的 Markdown/JSONL、素材或截图。
2. 需要备份或清理本地角色时，先打开“本地文档”确认实际目录，再从托盘退出程序。可复制整个角色文件夹备份；清理对话时同时处理 `memory` 中对应日期的 `.md` 和 `.jsonl`，清理长期记忆时编辑 `MEMORY.md`。要删除角色资料，可在退出后删除该角色整个文件夹；本地动态仍需另外处理。
3. 清理本地动态可在退出后删除 `local-companion/moments.json` 和 `schedules.json`；重新运行前如不希望再次生成，请先关闭“自动生成本地智囊团”。主动保存的截图需另外清理 `captures`。应用未提供覆盖以上所有目录的一键安全擦除功能。
4. Key 可用对应模型设置的清除入口移除。本机删除不会撤销服务商端的 Key、音色、历史或已发送到手机的文件；服务商数据需要在相应账号中处理。普通文件删除也不保证清除备份或恢复副本。

客户端修改无法修复服务端的计费身份、可信用量、平台凭据下发或额度预占问题。开源桌面代码不应被当作平台付费链路已经安全的证明。
