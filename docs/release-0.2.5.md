# AIBanlv 0.2.5：Cloudflare R2 收尾版

所有 Windows 更新文件只发布到 `download.aibanlv.ai` 对应 R2 桶，不向七牛云发布新包或清单，不自动回退旧源。
默认检查地址为 `https://download.aibanlv.ai/desktop-updates/windows/x64/latest.json`。

0.2.4 候选在真实较大差分读取中遇到长响应停顿，未发布清单。停顿的数据段拆成 6 个小请求后完整读回，SHA-256 一致。
0.2.5 将每个增量 Range 请求限制为最多 1 MiB，仍遵守原有 30 秒无数据、总时限、取消和完整哈希校验规则。
增加回归测试：服务端拒绝大范围时仍通过小范围增量重建，不回退完整下载，最终字节与原包完全一致。
0.2.4/0.2.5 包内图标、代码等相对 0.2.3 有更多变化，不能套用此前仅改版本时 1.25 MB 的下载量。

## 首次切换

0.2.3 及更早版本仍内置七牛云检查地址，需要从本地文件或 Cloudflare 手动安装一次：

```text
https://download.aibanlv.ai/desktop-updates/windows/x64/AIBanlv-0.2.5-win-x64-Setup.exe
```

先在托盘选择“退出”，再运行安装器并保留原安装目录；不需要卸载，不清理用户资料。文件占用时退出旧进程后重试，不点忽略。
安装后版本应为 0.2.5，默认从 Cloudflare 检查以后的更高版本；当前线上同为 0.2.5 时没有更新属于正常情况。
如曾设置旧 `PET_DESKTOP_UPDATE_URL`，清除或改为 Cloudflare；环境变量优先于默认源。
手动安装本身不会生成下载基线，后续更新有有效基线时优先增量，缺少基线时完整下载。

## 发布步骤

最终三个公开文件保存在 `demos/web-desktop-pet/dist/releases/0.2.5/`。
先上传 EXE 和 blockmap，校验后最后发布 latest.json；使用 `application/json` 和 `Cache-Control: no-store`，沿用两条 Bypass cache 规则。
保留旧 R2 对象和旧清单备份，问题版本可以停止分发；恢复清单不会自动降级已安装版本。
原有七牛云对象不删除、不覆盖，本次全部发布和验证请求使用 Cloudflare。
