# 更新记录

## 未发布

- 数字人空闲时跟随全桌面鼠标：慢速轻微转动、快速更明显，停下约 1.6 秒后平滑回正；
  鼠标长期不动会自己转眼并切换情绪，不触发在线对话。
- 跟随保留自然眨眼，抚摸、语音回复、动作预览及拖动窗口优先，窗口失焦时仍可跟随；
  开启鼠标穿透模式后数字人整体停止表情驱动。
- 视线跟随与空闲情绪合并为单一表情驱动，不再由两个控制器争抢眼睛和头部。

## 0.2.9 — 2026-11-11

- 修复手机消息向 Codex 原会话追加要求的链路，支持任务和项目选择，避免活动会话的写入冲突。
- 配合新版手机端，可选择 Codex、DeepSeek、Harness 或 WorkBuddy 发送消息；工具不可用时明确提示，不自动切换来源。
- 修复本地角色创建流程，形象包改为可选，未导入时沿用当前形象并支持创建后对话。
- Windows 安装包包含上述修复；手机功能需要匹配版本的手机端、设备绑定和已配置的桌面工具。WorkBuddy 每条消息创建新任务。

## 0.2.5 — 2026-10-28

- Windows 更新文件全部由 Cloudflare R2 分发，不自动回退七牛云；旧版手动安装一次完成切换。
- 每个增量范围请求最多 1 MiB，减少较长 CDN 响应中断的影响，保留完整哈希校验、取消和超时规则。
- 增加大改动区域分段下载回归测试；0.2.4 候选不发布清单。

## 0.2.4 — 2026-10-28

该版为验收候选，未发布更新清单，最终交付由 0.2.5 替代。

- Windows 更新默认源切换至 Cloudflare R2，清单、完整安装包和块图使用 `download.aibanlv.ai`。
- 保留增量重建、完整哈希校验、取消/超时处理、独立安装交接进程及任务栏品牌修复。
- 0.2.3 及更早版本需手动安装一次 0.2.4；本次不向七牛云发布新包或清单，不自动回退旧源。

## 0.1.4 — 2026-10-20

- 隐藏抚摸、轻点等触碰自动生成的用户消息气泡，保留数字人的文字回复、语音及口型。
- 普通文字、语音识别消息及未发送草稿的行为保持不变。

## 0.1.3 — 2026-10-20

- 修复首次绑定成功但未收到角色配置时一直等待形象的问题：短暂等待后自动请求一次重新同步。
- 没有服务端角色时，默认加载公共角色 waner（上官婉儿），沿用 Control 的角色目录与形象 ZIP 路径规则。
- 服务端角色优先；切换、解绑、断线和退出会取消未完成的默认角色加载，失败可重试。
- 新增首次绑定无需手机重新应用的回归与 Electron 真实渲染验收。
