# 本地角色与线上角色工作区

设备绑定保留 App 扫码入口，原账号表单改为本地配置。使用与当前线上语音相同的 Qwen Realtime 协议，用户自行填写 Realtime 和 DeepSeek API Key。Key 由主进程使用系统加密保存，不写入角色文档、不返回渲染器。本地角色不使用 AIBanlv 会话、积分、历史或智囊团接口；使用云端模型仍需联网，费用由用户自己的模型账号承担。

侧栏在工作空间之前增加角色列表，分为“线上公共 / 线上私有 / 本地私有”三个可展开菜单，默认全部收起。分类保留空状态，搜索时展开匹配结果，状态更新保留手动展开状态。新增按钮仅显示无边框“+”。点击角色进入文字对话，标题仅显示名称与操作，消息气泡旁显示头像，不在聊天标题展示提示词。提示词仅在编辑页维护。

创建页面只显示已配置的模式：本地使用统一模型设置，Realtime 或 DeepSeek Key / 已登录 Harness 客户端任一可用即可显示；创建克隆音色仍需自己的 Realtime Key。线上创建需设备已绑定。线上角色沿用服务端形象/音色训练及私有角色归属；本地导入已校验的 LAM ZIP、声音文件和提示词。

角色列表与“工作空间”使用同级侧栏分区，角色以二级列表直接展示，旁边“+”进入创建页；点击角色自动切换至右侧对话并聚焦输入框，内容区直接显示聊天，不再重复角色列表标题、外框或新增工具栏。对话占满剩余窗口高度，仅消息记录滚动，输入框固定可见，320/650/1024 宽度与高窗口均需验证。创建页隐藏简介输入，编辑已有角色时保留原简介。LAM 资产包标题旁的训练项目链接只通过受信设置窗口的专用 IPC 打开固定的 https://github.com/aigc3d/LAM，不允许传入任意 URL。Key 标签旁的“获取 Key”只能打开主进程白名单内的 DeepSeek API Keys 或与所选地域匹配的百炼 API Key 控制台，不允许任意 URL 或把 Key 拼进地址。

本地数字人渲染与窗口就绪判断必须使用本地模式，不能仍被旧的线上绑定条件阻挡。线上重连不移除本地 iframe，也不改变本地对话身份。默认启用人物区域鼠标穿透，输入卡片、工具按钮、拖动柄和实时记录仍保留鼠标操作；穿透只改变命中区域，不暂停渲染、口型或闲置表情。只有隐藏窗口才暂停动画。

手动刷新绑定优先在已连接的 WebSocket 重发注册，合并重复点击，替换码到达前保留原有效码；重复授权码不重复启动二维码生成。二维码过期后的注册同样有超时与有限重试，不能仅靠 pong 把缺失二维码的连接无限判定为健康。

本地文件放在用户数据目录的 local-companion 下，每个角色使用不可由用户路径控制的 UUID 目录。IDENTITY.md 保存角色资料说明，SOUL.md 保存人设，MEMORY.md 保存可编辑长期记忆，按本地日期保存 Markdown 对话及 JSONL 事件索引。只保存真实对话，不保存隐藏推理。导入资源复制到角色目录，关闭窗口和重启不丢失。线上绑定不会上传本地角色、记录或动态。

本地智囊团按当天真实用户对话安排随机时间，每角色每日最多一条。调度状态落盘，重启恢复；午夜后的旧任务不补发到新一天。仅程序运行时生成，用用户的 DeepSeek Key，不发送到 AIBanlv。生成只总结该角色当天已发生的对话，不虚构经历、不执行对话内工具指令。失败最多三次有限退避，设置可关闭自动生成。

## 模型与媒体去向

本地默认使用阿里云百炼 `qwen-audio-3.0-realtime-flash`。主进程按系统地区选服务：中国大陆 CN 使用北京，其它使用新加坡；不根据 UI 语言判断，不增加 GeoIP 请求，Key 必须匹配该地区。界面不提供地域选择。默认 Audio 模型不填 Workspace ID 时使用公共域名，选填项默认收进高级设置；要求专属空间的模型仍需该项。声音样本直接发送至自己 Key 对应的百炼音色复刻服务，语音、文字、人设和必要的本地历史发送至同一区域 Realtime；本地智囊团使用自己的 DeepSeek Key。本地私有仅指资料在本机管理，并不是离线大模型。

本地工作区与远端更新的 ModelSettings 共用一份 Realtime Key；兼容迁移旧 local-companion/realtime-key.json，一次成功后清除旧副本并记录迁移标记，避免清除 Key 后重启又被旧配置恢复。线上角色仍由平台计费，不因本地 Key 改变费用来源。设备绑定依次提供“扫码绑定 / 本地模式设置 / AI 工具状态”三个分页：扫码页绑定后用“设备已连接”替换二维码，短暂断线保持摘要；本地页仅显示本地设置与记录；工具页独立显示 Harness、Codex 和 WorkBuddy 状态，可由搜索进入。分页切换保留表单草稿，支持键盘左右键、Home/End；绑定成功不抢占当前分页，明确解除绑定时返回扫码入口。Realtime 模型与系统音色使用默认值，不展示编辑输入框；本地角色仍优先使用它自己的克隆音色。

角色分类只将已核实的公共目录条目标为线上公共。租户内无 userId 的角色、复制公共资产的私有角色以及手机分发但没有公共证明的角色，都归线上私有，不以 isDefault 或缺少 userId 推断公共权限。

文字输入状态共用主进程已解析的模型路由：线上积分不足、积分待确认、连接或模型不可用时，两个聊天入口同时禁用输入并说明原因；积分恢复自动启用并保留未发送草稿。自己的本地模型不受平台零积分限制。形象显示与聊天权限分开判断，不因零积分隐藏形象，已有回复的停止操作仍可用。

角色对话标题下始终按角色 source 标注费用来源：本地使用本地配置及用户自己的服务商额度，不消耗 AIBanlv 积分；线上使用 AIBanlv 在线积分，不回退到本地 Key。余额不足、平台拒绝会话和输入禁用统一提示“平台积分不足，请到 AIBanlv 手机端充值后继续对话”。配置不完整的本地角色只提示补充本地配置，不切换平台计费，也不提示充值可解锁本地模型。

本地角色加载 local: 资产必须跳过仅允许 HTTPS 的线上磁盘缓存，直接从本地工作区读取；不得先进入线上地址白名单而阻断读取，也不得在失败时下载线上替代形象。缺少本地文件时提示重新导入 LAM，而不是检查网络或在 App 重新分发。

AI智囊团菜单从已加载动态及本地动态中选择时间最新的发圈角色头像，忽略用户动态和评论；没有角色动态、图片无效或加载失败时使用默认图标。每个绑定账号首次就绪时只预取一次受鉴权的动态首页（最多 20 条），之后复用页面刷新结果；菜单隐藏时不轮询，不为了找头像遍历历史。账号改变立即清除上一账号的线上头像来源，本地动态保持本机隔离。

LAM ZIP 支持必需文件在根目录或同一嵌套目录：skin.glb、animation.glb、offset.ply、vertex_order.json。禁止多角色、路径穿越、符号链接、加密、重复文件，保留 64 MiB 压缩包、512 MiB 展开及 256 项限制。验证后仅在本机将导入副本整理到显式 oac/ 目录，兼容渲染器的目录入口要求；不修改用户原包，不上传平台。照片可选作为列表头像。

线上创建提交前必须同意媒体处理说明：照片、声音使用沿用手机端的七牛存储 `zhanlvgpt.ieasysell.com`，媒体链接可公开访问，保留至清理；照片经审核后交给 `train.ieasysell.com` 训练，声音交给阿里云百炼创建音色。不要上传未获授权或不适合公开访问的素材。本次实现与验证不上传真实媒体，也不调用真实训练。

## 线上鉴权与发布顺序

远端更新后，私有角色目录与语音会话通过 DeviceHttpAuth 使用配对证明换取短时设备 JWT，再调用受保护的 /jwt/client/desktop/roles、sessions 等接口（详见 scan-jwt-spec.md）。目录等待配对证明就绪，再自动刷新；不再调用旧 role_catalog WebSocket action，也不在鉴权失败后降级访问未鉴权业务接口。公共目录仅使用远端既定的 desktop-public/roles 窄接口；公开形象可预览，线上对话仍需绑定与积分。上传授权、创建及结果查询继续使用受绑定授权的控制 WebSocket。手机控制连接每帧携带当前有效登录 JWT，后端验证签名、过期、撤销状态与账号状态，再由服务端确定用户和租户；转发前删除 JWT。已绑定电脑首次注册需通过配对密钥的 HMAC 挑战，再接收业务挑战。设备码、用户 ID、租户 ID 或接口 URL 本身都不授予权限。

后端角色会话会检查公共/私有归属，禁止指定其他账号的私有角色；HTTP 对应业务路径及其历史别名要求登录。登录、扫码握手与可公开下载的静态资源不是私有业务接口；头像 CDN 资源仍按现有公开链接政策提供。本轮没有对整套旧业务后端进行完整渗透测试，不应将源码测试当成生产安全保证。

发布时需先在测试环境应用后端 `docs/control-role-creation.sql`，再协调发布后端、手机控制端和桌面端。**旧手机控制协议不携带 JWT，将被新后端拒绝；缺少本机配对密钥的历史绑定需在 App 解绑后重新扫码。** 原有控制 WebSocket 的单实例/共享路由要求不变。模型和存储管理密钥只放后端部署配置，不写入桌面代码、角色文档或渲染器状态。

创建请求有持久化幂等记录。客户端超时仅查询原请求，不自动重新训练。后端进程在处理中退出时，结果可能保持待确认；应核对上游训练与角色库再由运维处理，不要通过换请求 ID 连续重试。未完成上传的媒体清理沿用存储侧管理流程，本实现不声称已具备自动清理策略。

验证使用本地 HTTP/WebSocket 夹具与合成资产，不创建真实付费会话、音色、形象或动态。运行根目录 npm test 和现有 Electron/浏览器设置夹具；本轮不构建安装包。
